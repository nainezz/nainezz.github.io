# nainezz.github.io

Phone shop website of **Nainezz**: quality ex-UK and ex-USA smartphones in Nairobi, Kenya.

Developer portfolio: https://nainezz.github.io/portfolio/

**Live:** https://nainezz.github.io

## What's on the site

- **Phones for sale:** a filterable list with storage, grade and battery health. Each phone has a WhatsApp order button.
- **About and contact:** WhatsApp and Instagram links.

## Editing content

Everything lives in one file, `index.html`. The site's content is defined near the bottom, in the `<script>` section:

- `SITE`: name, WhatsApp number, Instagram, location
- `PRODUCTS`: phones for sale (model, storage, grade, battery, origin, price)

Built with plain HTML, CSS and JavaScript and hosted on GitHub Pages.
